# Финзарядка — кликабельный прототип

Прототип трека «Инвестиции»: раздел 1 «Как растут деньги» и раздел 2 «Что покупают на бирже». Открывается в браузере любого телефона, регистрация не нужна.

## Что внутри

| Файл | Экран |
|---|---|
| `index.html` | Вход, цель, входной тест, карта трека, боссы разделов (экстерн) |
| `compound.html` | Урок 1 · Сложный процент (песочница с ползунками) |
| `review.html` | Следующий день · Повторение с новыми цифрами |
| `inflation.html` | Урок 2 · Инфляция |
| `risk.html` | Урок 3 · Машина времени: 2022 год на бирже |
| `pyramid.html` | Урок 4 · Переписка: друг зовёт в пирамиду |
| `stocks.html` | Урок 5 · Акции: доля в бизнесе (новости «дороже или дешевле», пары) |
| `bonds.html` | Урок 6 · Облигации: купоны и качели ставки |
| `funds.html` | Урок 7 · Фонды: собери индекс сам и гонка черепах |
| `broker.html` | Урок 8 · Брокер, комиссии и налог: расследование отчёта |
| `support.js` | Мини-движок, который показывает экраны. Без зависимостей |
| `.nojekyll` | Служебный файл для GitHub Pages: просит выложить файлы как есть. Если не загрузится — не страшно |

Уроки связаны ссылками: урок 1 → повторение → урок 2 → урок 3 → урок 4 → карта и босс. Раздел 2 открывается с карты: урок 5 → 6 → 7 → 8 → карта и босс раздела.

## Как выложить на GitHub Pages

1. Создай новый репозиторий, например `finzaryadka`, и сделай его **Public**: на бесплатном тарифе GitHub Pages работает только с публичными репозиториями.
2. В репозитории: **Add file → Upload files**. Перетащи все файлы из архива (сами файлы, а не архив целиком) и нажми **Commit changes**.
3. **Settings → Pages**. В блоке «Build and deployment» выбери Source: **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажми **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://<твой-логин>.github.io/finzaryadka/`. Открой его с телефона через мобильный интернет и пройди хотя бы урок 1.

Чтобы обновить сайт, загрузи новые версии файлов тем же способом: GitHub заменит старые.

## Как посмотреть на компьютере

В папке с файлами выполни `python3 -m http.server` и открой http://localhost:8000.

## Ограничения прототипа

- Прогресс не переходит между страницами: карта не отмечает пройденные уроки.
- Внутри одной страницы прогресс сохраняется до закрытия вкладки. Повторный заход на урок вернёт тебя туда, где ты остановился. Начать заново можно кнопкой «Пройти урок заново» или крестиком.
- Аналитики нет: где застревают тестировщики, видно только при личном наблюдении.
- Сайт публичный: его откроет любой, у кого есть ссылка. Поисковикам индексировать его запрещено (`noindex`).
- Шрифт Manrope подгружается из Google Fonts. Если не загрузится, будет системный шрифт.
- Цифры в уроках учебные и не являются инвестиционной рекомендацией. Истории и компании вымышлены, рыночные данные 2022 года — реальные.
